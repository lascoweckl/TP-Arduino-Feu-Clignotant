Utiliser Arduino IDE 2

Créer et enregistrer un programme, sélectionner l’Arduino Uno et son port COM, vérifier le code puis le téléverser dans la carte.

Objectif

Du programme à la carte Arduino

À la fin de cette fiche, tu dois être capable de programmer une Arduino Uno sans aide : créer un sketch, le sauvegarder, sélectionner la carte et le port série, compiler puis téléverser.

1. Nouveau sketch
2. Enregistrer
3. Carte + COM
4. Vérifier
5. Téléverser
1

Créer un nouveau programme

Dans Arduino IDE 2, un programme Arduino est appelé un sketch. Pour démarrer un nouveau travail, utilise Fichier → Nouveau sketch. L’éditeur affiche la structure minimale avec setup() et loop().

2

Enregistrer le fichier

Enregistre le travail dès le début avec Fichier → Enregistrer sous…, puis donne un nom explicite au projet, par exemple Feu_Velo. Utilise ensuite régulièrement Ctrl + S.

Bonne pratique : un nom court et explicite, sans caractères spéciaux, facilite le rangement et l’identification du programme.
3

Choisir la bonne carte et le bon port COM

Branche l’Arduino Uno au PC avec le câble USB. Sur les postes utilisés au lycée, effectue les deux réglages depuis le menu Outils.

1 — Choisir la carte

Clique sur Outils → Carte, puis sélectionne Arduino Uno.

2 — Choisir le port de communication

Clique ensuite sur Outils → Port, puis sélectionne le port COM correspondant à la carte, par exemple COM6.

Attention : le numéro du port COM n’est pas toujours le même. Il peut être COM5, COM6, COM7… et peut changer d’un ordinateur à l’autre. Ne recopie donc pas simplement le numéro COM d’un camarade.
Astuce : si tu ne sais pas quel port choisir, regarde les ports disponibles, débranche l’Arduino, puis rebranche-le. Le port qui réapparaît correspond normalement à la carte.
4

Compiler : vérifier le programme

Clique sur le bouton ✓ Vérifier. L’IDE analyse le sketch et le compile. Une erreur de syntaxe empêche la compilation : lis alors le message affiché dans la console en bas de la fenêtre et corrige le programme.

À retenir : compiler ne programme pas encore l’Arduino. Cette étape permet de vérifier que le code peut être transformé en programme exécutable pour la carte.
5

Téléverser dans l’Arduino

Lorsque le programme compile correctement et que la bonne carte ainsi que le bon port sont sélectionnés, clique sur → Téléverser. L’IDE compile puis transfère le programme dans la mémoire du microcontrôleur.

Pendant le transfert, les voyants RX/TX de la carte peuvent clignoter. Attends la fin du téléversement avant de débrancher l’Arduino.

En cas de problème

  • Vérifier que le câble USB est correctement branché.
  • Vérifier que Arduino Uno est bien la carte sélectionnée.
  • Vérifier le port COM.
  • Lire la première erreur utile indiquée dans la console.
  • Relancer d’abord ✓ Vérifier, puis → Téléverser.
Erreur fréquente : si la compilation réussit mais que le téléversement échoue, vérifier en priorité la connexion USB et le port COM sélectionné.
